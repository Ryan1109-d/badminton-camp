# 台灣大學羽球冬令營 2027 — 報名網站

> 與足球營（football-camp）為獨立專案：獨立 repo、獨立 GAS、獨立 Google Sheet，互不共用。

## 檔案結構

| 檔案 | 用途 |
|------|------|
| `index.html` | 首頁（介紹/課程/時程/收費+退費/FAQ） |
| `signup.html` | 報名頁（表單 + GAS 串接，含三時段選擇） |
| `gas-backend.js` | Google Apps Script 後端（貼到 Apps Script 編輯器用） |

## 部署流程

### 1. 後端（Google Apps Script，羽球專屬新 Sheet）
1. 用 stayyoung 信箱開一個**新的** Google Sheet，第一列填 18 欄：`報名時間 | 梯次 | 時段 | 學員姓名 | 性別 | 年齡 | 年級 | 收信信箱 | 緊急聯絡人 | 緊急聯絡人電話 | 繳款人姓名 | 繳款人電話 | 繳款人信箱 | 優惠身份 | 午餐 | 狀態 | 團報成員 | 衣服尺寸`
2. 擴充功能 → Apps Script → 貼上 `gas-backend.js` 內容
3. 改 `CONFIG.SHEET_ID`
4. 部署為網頁應用程式（執行身分：我；存取：所有人）
5. 複製 Web App URL

### 2. 前端
1. `signup.html` 的 `GAS_URL` 換成上面的 URL
2. Push 到 GitHub repo，開啟 GitHub Pages

## 候補機制（已內建於 GAS）
- 同梯次總報名（三時段合計）第 1–50 位：狀態「正取」，寄報名確認信
- 第 51 位起：狀態「候補」，寄候補通知信
- 候補遞補通知：**手動操作**，之後可加後台功能
